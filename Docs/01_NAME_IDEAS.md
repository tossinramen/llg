# Name Ideas

The game will teach several languages, so the name should not be tied to Spanish.
The project currently uses **Babelbrook** as a working title. To change it, edit one line:
`Assets/Scripts/Core/GameConfig.cs` → `Title`.

## Shortlist

| Name | Why it works |
|---|---|
| **Babelbrook** | "Babel" (many languages) + a cosy village name. Sounds like a place you can visit. |
| **Lexicove** | Lexicon + cove. Short, easy to spell, fits a seaside/fishing town. |
| **Tonguetide** | Language + ocean. Good if the world is islands, one per language. |
| **Wordhaven** | Friendly and obvious. Tells people it is about words straight away. |
| **Phrasewood** | A forest setting; "phrase" hints at sentence building. |
| **Lingovale** | Lingo + vale (valley). Classic RPG-town feel. |

## More options

- **Polyglot Harbor** – every ship brings a new language (nice hook for adding Korean/Japanese later)
- **Tales of Babelbrook** – longer, SNES-box-art style version of the working title
- **The Wandering Word**
- **Verbwick**
- **Glossary Grove**
- **Wordwake**
- **Echo Isle** – learning by repeating/echoing
- **First Words**

## Round 2 (Babelbrook rejected)

- **Cozy / village:** Wordwhistle, Hearthtongue, Lanternleaf, Mossmouth, Pebblespeak
- **Adventure / quest:** Quest for Words, The Polyglot's Path, Runes of Speech, Tongues of the Realm, Lexica Legends
- **Short and catchy:** Parla, Wordling, Lingo Quest, Babble, Hablo
- **Travel / world:** Passport Kingdom, Far Words, Wayfarer's Tongue, Words Across the Sea
- **Top picks:** Wordling, Lanternleaf, The Polyglot's Path

## Before you commit to one

1. Search the name on Steam, itch.io, Google Play and the App Store.
2. Check the `.com` domain and social handles.
3. Say it out loud to someone and ask them to spell it. If they can't, people can't search for it.

I have not checked any of these for existing games or trademarks, so do step 1 before you get attached.
