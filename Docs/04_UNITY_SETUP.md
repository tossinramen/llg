# Unity Setup (for someone new to Unity)

This folder (`Downloads\llg`) **is** the Unity project. You do not need to create a new
project or copy files anywhere.

## Open the game for the first time

1. Open **Unity Hub**.
2. Click **Add** (top right) → **Add project from disk**.
3. Choose the folder `C:\Users\tahsi\Downloads\llg` and confirm.
4. The project appears in the list with editor version **2022.3.19f1** (already installed on
   this PC). Click it.
5. Wait for Unity to load. The first time can take a few minutes.
6. Open the start screen. Easiest: top menu **LLG → Build Start Screen Scene** (it builds and
   opens it). Or use the **Project** panel (the file browser tab at the bottom, *not* the
   "Assets" menu at the top): open `Assets` → `Scenes` and double-click **StartScreen**.
   If you can't see the Project panel, click **Layout → Default** at the top right.
7. Press the **Play ▶** button at the top centre. The start screen appears in the **Game** tab.
8. Press Play again to stop.

The scene looks empty until you press Play. That is normal: the start screen builds its
buttons from code when the game runs.

If `StartScreen` is ever missing or broken, use the menu at the very top of the Unity window:
**LLG → Build Start Screen Scene**. It recreates the scene.

**Tip:** in the Game tab, change the dropdown that says "Free Aspect" to **16:9** so you see
the screen as designed.

## The five Unity words you need

| Word | Meaning |
|---|---|
| **Project panel** | The file browser at the bottom. It shows the `Assets` folder. |
| **Scene** | One screen or level of the game (start screen, town…). Saved as a `.unity` file. |
| **GameObject** | A thing in a scene (the camera, the player, a button). Listed in the **Hierarchy** panel on the left. |
| **Component / Script** | Behaviour attached to a GameObject. Scripts are `.cs` files written in C#. |
| **Play mode** | Running the game inside the editor with the ▶ button. Changes made while playing are lost when you stop. |

## How files I make get into Unity

Because we are working inside the project folder, **I write files directly where Unity expects
them and Unity picks them up automatically**. When you click back into the Unity window you will
see a short "Importing…" bar; after that the new files are there. There is no import step for you.

If you ever need to add a file yourself (a sound, a picture you drew), drag it from Windows
Explorer into the right folder in Unity's Project panel.

## Where things live

```
llg/
├─ Assets/                    everything Unity uses
│  ├─ Scenes/                 screens/levels (.unity files)
│  ├─ Scripts/                C# code
│  │  ├─ Core/                shared settings (game title, language list)
│  │  ├─ Player/              profile, appearance, HP/mana/hunger
│  │  ├─ Skills/              skill XP and levels
│  │  ├─ Language/            loads word packs
│  │  ├─ UI/                  start screen, character preview
│  │  └─ Activities/          minigames will go here
│  ├─ Resources/              files the game loads by name while running
│  │  ├─ Art/Character/       character layers (skin, hair, shirt, pants)
│  │  ├─ Art/Icons/           item and food pictures
│  │  ├─ Art/UI/              backgrounds, hearts, symbols
│  │  ├─ Art/Tiles/           map tiles (empty for now)
│  │  └─ Languages/es/        the Spanish word pack (pack.json)
│  ├─ Audio/Music, Audio/SFX  sound (empty for now)
│  ├─ Prefabs/                reusable objects (empty for now)
│  ├─ Fonts/                  pixel fonts (empty for now)
│  └─ Editor/                 tools that only run inside Unity, not in the game
├─ Docs/                      these documents
├─ Tools/art/                 the script that draws the pixel art
├─ Packages/, ProjectSettings/   Unity configuration – leave alone
└─ Library/, Temp/, Logs/     created by Unity – safe to ignore, never edit
```

Unity also creates a `.meta` file next to every file in `Assets`. Leave them where they are, and
if you move or rename something in `Assets`, **do it inside Unity** (not Windows Explorer) so the
`.meta` file follows it.

## About the art

All art is generated by `Tools/art/generate_art.py`. Any image saved under a folder named `Art`
is automatically set up as crisp pixel art (`Assets/Editor/PixelArtImporter.cs` does this), so
no import settings need changing.

Character sprites are drawn in grey and coloured by the game, which is how one set of drawings
gives every skin, hair and clothing colour.

## If something goes wrong

- **Red errors in the Console panel** (bottom, next to Project): copy the first one and send it to me.
- **Pink or blurry images**: right-click the `Art` folder in the Project panel → **Reimport**.
- **Unity Hub says the editor version is missing**: install 2022.3.19f1 from Hub → Installs.
