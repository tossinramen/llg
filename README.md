# Babelbrook (working title)

A single-player, 16-bit style RPG for learning languages. Spanish first; Japanese and Korean planned.

## Read these in order

1. [Docs/04_UNITY_SETUP.md](Docs/04_UNITY_SETUP.md) – open the project in Unity and press Play
2. [Docs/02_GAME_DESIGN.md](Docs/02_GAME_DESIGN.md) – the whole game plan: stats, skills, 15 activities
3. [Docs/01_NAME_IDEAS.md](Docs/01_NAME_IDEAS.md) – name ideas
4. [Docs/03_LANGUAGE_DATA.md](Docs/03_LANGUAGE_DATA.md) – where vocabulary and grammar data comes from
5. [Docs/05_TODO.md](Docs/05_TODO.md) – the to-do list, in build order

## What exists so far

- A Unity 2022.3 project with organised folders
- A working start screen: character creator, turnable character, language picker
- Placeholder pixel art: character layers, title background, food and UI icons
- Starter Spanish word pack (43 words, 12 sentences)
- Code foundations for HP/mana/hunger, skills and language packs (not yet used in gameplay)
